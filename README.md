# DLNA Cast 3.1.0

**DLNA Cast** — проект для интеграции медиаплеера Lampa с телевизорами и другими устройствами, поддерживающими DLNA / UPnP.

Проект предназначен для передачи воспроизводимого в Lampa видео на совместимое сетевое устройство, например телевизор Samsung, через локальную сеть Wi-Fi или Ethernet.

## 1. Возможности проекта

- Поиск DLNA-устройств в локальной сети с использованием SSDP.
- Ручное добавление телевизора по IP-адресу.
- Обнаружение и определение параметров DLNA-устройства.
- Управление воспроизведением через UPnP SOAP.
- Передача видеоссылки с Lampa на выбранное устройство.
- Дополнительное проксирование HTTP-видеопотоков.
- Поддержка обработки HLS-плейлистов и связанных с ними ресурсов через прокси.
- Настройка Referer, User-Agent, Cookie и Authorization для прокси.
- Автоматическое переподключение при некоторых ошибках воспроизведения.
- Кнопка DLNA непосредственно в интерфейсе видеоплеера Lampa.

Доступность отдельных возможностей зависит от телевизора, источника видео, сети и настроек устройства.

## 2. Состав проекта

В репозитории находятся три основных файла.

### Index_3.1.0.js

Основной плагин для Lampa.

Отвечает за:
- интерфейс DLNA Cast;
- выбор и сохранение устройств;
- поиск и добавление телевизоров;
- взаимодействие с Python Bridge;
- передачу видеоссылок;
- кнопку DLNA в плеере;
- настройки проксирования и переподключения.

### dlna_bridge_3.1.0.py

Локальный Python-сервер (Bridge).

Отвечает за:
- обнаружение устройств через SSDP;
- определение DLNA-сервисов;
- отправку команд UPnP SOAP;
- управление воспроизведением;
- HTTP-проксирование видеопотоков;
- обработку HLS-плейлистов.

Требуется Python 3.8 или новее. Используются стандартные библиотеки Python.

### cors-server.js

Дополнительный локальный Node.js-сервер для раздачи JavaScript-плагина с CORS-заголовками.

Использовался для локальной установки плагина. При загрузке плагина напрямую из GitHub Pages этот сервер не требуется.

## 3. Схема работы

1. Lampa загружает JavaScript-плагин из GitHub Pages.
2. Пользователь выбирает телевизор или добавляет его вручную.
3. Плагин обращается к локальному Python Bridge.
4. Bridge обнаруживает DLNA-устройство и передаёт ему команды управления.
5. Телевизор получает адрес видеопотока и пытается воспроизвести его.
6. При включённом прокси видеопоток проходит через Python Bridge.

**Важно:** GitHub используется для хранения и распространения исходного кода. Сам Python Bridge должен работать на устройстве, доступном по локальной сети для Lampa и телевизора.

## 4. Требования

- Медиаплеер Lampa.
- Телевизор или другое устройство с поддержкой DLNA / UPnP.
- Общая локальная сеть для устройства с Python Bridge и телевизора.
- Python 3.8 или новее.
- Для локального запуска CORS-сервера — Node.js (необязательно при использовании GitHub Pages).

## 5. Установка плагина в Lampa

После публикации проекта через GitHub Pages плагин можно подключить по адресу:

`https://coyoten763.github.io/lampa-dlna-cast/Index_3.1.0.js`

Добавьте этот адрес в список плагинов Lampa.

## 6. Запуск Python Bridge

В каталоге с файлом `dlna_bridge_3.1.0.py` выполните:

```bash
python dlna_bridge_3.1.0.py
```

По умолчанию сервер использует порт `8099`.

Проверка работоспособности:

```text
http://127.0.0.1:8099/ping
```

Ожидаемый ответ:

```json
{"ok":true,"version":"3.1.0"}
```

Если Bridge работает на телефоне, в настройках плагина укажите его локальный IP-адрес:

```text
http://IP_ТЕЛЕФОНА:8099
```

Например:

```text
http://192.168.1.50:8099
```

Замените пример на фактический IP-адрес устройства.

## 7. Настройки прокси

Проксирование видеопотока отключено по умолчанию.

При необходимости его можно включить в настройках DLNA Cast.

Порт прокси должен совпадать с портом Python Bridge — по умолчанию `8099`.

Телевизор должен иметь сетевой доступ к IP-адресу устройства, на котором работает Bridge.

## 8. Безопасность

- Используйте Bridge только в доверенной локальной сети.
- Не открывайте порт `8099` в интернет и не настраивайте его проброс на публичный адрес без отдельной защиты.
- Не публикуйте Cookie, Authorization-токены, пароли и личные настройки.
- Не размещайте в публичном репозитории персональные конфигурации и секретные данные.

## 11. Назначение проекта

DLNA Cast создаётся для удобной передачи видео из Lampa на телевизор без необходимости устанавливать отдельное приложение Lampa непосредственно на телевизоре.

GitHub-репозиторий предназначен для хранения исходного кода, публикации версий и дальнейшего развития проекта.
